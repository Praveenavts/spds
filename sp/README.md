# Student Performance Data Analytics & Data Science Project

This is a beginner-friendly Data Analytics and Data Science project using Python and Streamlit.

## Project Features

- Dataset preview
- Student performance analytics dashboard
- Pass/fail analysis
- Study hours vs final marks chart
- Correlation analysis
- Machine Learning final marks prediction
- Model performance report

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Scikit-Learn

## Local Run Command

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

Upload all files to GitHub, then deploy using Streamlit Community Cloud.
Main file path: `app.py`
